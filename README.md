# CATIA Mechanical Part (Clevis / Fork Design)

This repository contains the 3D CAD model and 2D technical drawing for a mechanical component designed using **Dassault Systèmes CATIA**.

## 📁 Repository Structure

* **`3D_Model/`**: Contains the native CATIA 3D part file (`.CATPart`).
* **`2D_Drawing/`**: Contains the 2D drafting / blueprint file (`.CATDrawing`).
* **`Renders/`**: Visual previews and renderings of the finished model.

## 🛠️ Software Requirements
* **Software:** CATIA V5 (or compatible versions)
* **Modules Used:** Part Design, Sketcher, Drafting

## 📥 How to Use
1. Clone or download this repository as a ZIP file.
2. Open **CATIA**.
3. Navigate to `3D_Model/part.CATPart` to view or modify the 3D geometry.
4. Open the `2D_Drawing/` folder to check the manufacturing dimensions and tolerances.
